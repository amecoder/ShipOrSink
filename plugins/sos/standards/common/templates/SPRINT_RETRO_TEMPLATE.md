## 진행 규칙

| 항목 | 내용 |
|------|------|
| **전체 시간** | 60분 (타이머 엄수) |
| **단계별 시간** | Keep 15분 / Problem 15분 / Try 15분 / Action Items 15분 |
| **핵심 원칙** | 비난 금지 -- 사람이 아닌 프로세스에 집중한다 |
| **발언 규칙** | 한 사람씩 순서대로, 중간에 끊지 않는다 |
| **투표** | Try 항목이 많을 경우 점 투표(Dot Voting)로 우선순위 결정 |
| **기록** | 퍼실리테이터가 실시간 기록, 회고 직후 팀 채널에 공유 |
